# Why there is no front end

The five jobs here are catalogue maintenance, bundle checks, discount review, quote preparation and Monday follow-up. A database and a coding agent can perform those jobs without a browser form.

The database keeps the rules and history. The CLI performs validated transactions. Claude Code, Codex, OpenCode and Cursor use the same recipes. Read-only HTML gives the sales manager a weekly view and printable quote drafts.

A full quoting screen adds guided configuration, inline editing, a customer portal, signatures and mobile access. This free base does not provide those experiences, offline synchronisation or live collaboration. Its required-component rules are not a general constraint solver. Recurring pricing, tax determination and billing require separate systems or an agreed extension.

Enterprise DNA builds the screens and connections your process needs through Omni by Enterprise DNA. The free version fits a trusted operator preparing product quotes and reviewing exceptions. It is not a replacement for the entire Revenue Cloud suite.

Local PGlite supports one process at a time. Shared Postgres needs authenticated access, role restrictions and backups. Neither an operator name in a command nor an HTML draft establishes customer consent.
